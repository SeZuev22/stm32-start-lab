# Что реализовано

Сохранённый тест:

```text
5 миганий
ON 300 мс
OFF 300 мс
↓
пауза 2000 мс
↓
повтор
```

Используется:

```c
HAL_GPIO_WritePin()
HAL_Delay()
for
while (1)
```

Этот алгоритм нужен как проверка того, что:

- CubeMX настроен правильно;
- HAL работает;
- ST-LINK подключён;
- прошивка записывается;
- PC13 управляет встроенным LED.
