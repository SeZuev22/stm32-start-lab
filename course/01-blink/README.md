# Лабораторная работа №1 — Blink

[← Подготовка рабочего места](../00-getting-started/README.md) | [↑ Карта курса](../README.md)

## Название работы

Создание первого проекта STM32 и управление цифровым выходом GPIO.

## Цель работы

Освоить базовый цикл разработки проекта STM32:

**настройка → генерация проекта → программирование → сборка → прошивка → проверка результата.**

## Используемое оборудование

- Blue Pill;
- STM32F103C8T6;
- ST-LINK V2;
- соединительные провода;
- компьютер под управлением Windows.

## Ожидаемый результат

Встроенный светодиод:

1. мигает 5 раз;
2. делает паузу 2 секунды;
3. повторяет последовательность.

> Полная лабораторная работа будет оформлена на следующем этапе.
