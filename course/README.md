# STM32 Start Lab — учебный курс

[← На главную](../README.md)

---

Курс предназначен для первого знакомства со STM32 и строится по принципу:

```text
объяснение
↓
обязательное действие
↓
проверка
↓
самостоятельное задание
↓
защита результата
```

Текущий проверенный трек:

**Windows → Blue Pill STM32F103C8T6 → ST-LINK V2 → STM32CubeMX → STM32CubeIDE → HAL**

---

# Порядок прохождения

Материалы выполняются последовательно:

```text
00 — Подготовка рабочего места
↓
01 — GPIO Output: Blink
↓
следующие лабораторные работы после утверждения и практической проверки
```

Пропуск обязательных этапов не предполагается.

---

# 00 — Подготовка рабочего места

Требуется:

- подготовить Blue Pill STM32F103C8T6;
- подготовить ST-LINK V2;
- скачать проверенный Windows-комплект;
- установить STM32CubeMX 6.18.1;
- локально установить STM32CubeF1 v1.8.0;
- установить STM32CubeIDE 2.2.0;
- проверить готовность среды.

➡️ **[Выполнить подготовку рабочего места](00-getting-started/README.md)**

---

# Лабораторная работа №1 — GPIO Output: Blink

Работа состоит из трёх обязательных частей:

```text
А — базовый проект по инструкции
Б — исследование HAL_GPIO_TogglePin()
В — индивидуальный вариант
```

В ходе работы студент должен:

- создать проект STM32F103C8T6;
- настроить SWD;
- настроить PC13 как GPIO Output;
- использовать HAL;
- собрать и прошить проект;
- получить базовый Blink на реальной плате;
- разобраться в `HAL_GPIO_TogglePin()`;
- выполнить индивидуальный световой алгоритм по одному из 10 вариантов;
- рассчитать длительность полного цикла;
- оформить и защитить результат.

➡️ **[Выполнить лабораторную работу №1](01-blink/README.md)**

# Стандарт лабораторной работы STM32 Start Lab

Каждая следующая лабораторная работа оформляется по единой структуре:

1. цель;
2. исходные данные и оборудование;
3. необходимая теория;
4. относящиеся к теме первоисточники;
5. пошаговая базовая часть;
6. объяснение каждой настройки и функции;
7. Build / Flash / проверка на реальном оборудовании;
8. контрольная точка базовой части;
9. обязательный новый элемент для самостоятельного разбора;
10. индивидуальное задание на 10 вариантов;
11. расчёт или проверка результата, если это применимо;
12. контрольная точка индивидуальной части;
13. типичные ошибки;
14. контрольные вопросы;
15. требования к отчёту;
16. критерии защиты.

## Методический принцип

Индивидуальный вариант не должен требовать материала следующей лабораторной работы.

Студент получает все необходимые знания в текущей работе, но готовое решение своего варианта не получает.

То есть:

```text
показать принцип
≠
дать готовый индивидуальный ответ
```
