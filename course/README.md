# STM32 Start Lab — учебный курс

Добро пожаловать в **STM32 Start Lab**.

Этот курс предназначен для студентов, которые раньше не работали с микроконтроллерами STM32 и хотят пройти путь **от первого подключения платы до самостоятельной разработки программ**.

Текущий учебный трек:

**Windows → Blue Pill STM32F103C8T6 → ST-LINK V2 → STM32CubeMX → STM32CubeIDE → HAL**

---

# 🚀 Как проходить курс

Если вы впервые работаете со STM32, не переходите сразу к исходному коду.

Проходите материалы последовательно:

```text
00 — Подготовка рабочего места
          ↓
01 — Лабораторная работа №1: Blink
          ↓
02 — Следующая лабораторная работа
          ↓
...
```

Каждый раздел содержит ссылки на следующий шаг.

---

# 00 — Подготовка рабочего места

Перед первой лабораторной работой необходимо подготовить компьютер и оборудование.

В этом разделе вы:

- узнаете, что потребуется для работы;
- подготовите Blue Pill STM32F103C8T6;
- подготовите ST-LINK V2;
- скачаете необходимое программное обеспечение;
- установите STM32CubeMX;
- установите локальный STM32CubeF1;
- установите STM32CubeIDE;
- настроите работу без автоматических обновлений;
- проверите готовность среды разработки.

➡️ **[Начать подготовку рабочего места](00-getting-started/README.md)**

# 🧪 Лабораторные работы

## Лабораторная работа №1 — Blink

### Создание первого проекта STM32 и управление цифровым выходом GPIO

В первой лабораторной работе вы:

- создадите проект для STM32F103C8T6;
- познакомитесь с STM32CubeMX;
- включите интерфейс SWD;
- настроите вывод PC13;
- познакомитесь с GPIO;
- познакомитесь с библиотекой HAL;
- напишете первую программу;
- соберёте проект;
- подключите ST-LINK V2;
- прошьёте реальный микроконтроллер;
- проверите результат на встроенном светодиоде.

Ожидаемый результат:

```text
5 миганий
→ пауза 2 секунды
→ повтор
```

➡️ **[Перейти к лабораторной работе №1](01-blink/README.md)**

# 📚 Как устроена каждая лабораторная работа

Все лабораторные работы оформляются по единому шаблону:

1. цель работы;
2. что необходимо знать;
3. необходимое оборудование;
4. необходимое программное обеспечение;
5. используемая документация;
6. схема подключения;
7. настройка STM32CubeMX;
8. объяснение выбранных настроек;
9. генерация проекта;
10. структура проекта;
11. программный код;
12. объяснение кода;
13. сборка;
14. прошивка;
15. проверка результата;
16. типичные ошибки;
17. контрольные вопросы;
18. самостоятельное задание;
19. требования к отчёту;
20. вывод.

Главная задача курса — не просто получить работающий код, а **понимать, почему программа работает именно так**.
