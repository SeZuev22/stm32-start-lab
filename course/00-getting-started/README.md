# Добро пожаловать в STM32 Start Lab

Этот раздел предназначен для студентов, которые раньше **никогда не работали со STM32**.

Не требуется заранее знать:

- STM32CubeMX;
- STM32CubeIDE;
- HAL;
- GPIO;
- ST-LINK;
- SWD;
- структуру STM32-проекта.

На этом этапе необходимо только подготовить оборудование и рабочую среду.

После выполнения раздела компьютер и оборудование должны быть готовы к первой лабораторной работе.

---

# Что будет сделано

В ходе подготовки вы:

1. подготовите необходимое оборудование;
2. познакомитесь с Blue Pill;
3. познакомитесь с ST-LINK V2;
4. скачаете необходимое программное обеспечение;
5. установите STM32CubeMX;
6. локально установите STM32CubeF1;
7. установите STM32CubeIDE;
8. подготовите рабочую папку;
9. отключите ненужные автоматические обновления;
10. проверите готовность рабочего места;
11. перейдёте к лабораторной работе №1.

---

# 1. Что потребуется

Для первой лабораторной работы необходим минимальный комплект.

## Обязательно

- Blue Pill;
- микроконтроллер STM32F103C8T6;
- ST-LINK V2;
- 4 соединительных провода Dupont;
- USB-кабель для ST-LINK;
- компьютер с Windows.

## Не требуется для первой работы

На первом занятии не нужны:

- макетная плата;
- внешний светодиод;
- резисторы;
- логический анализатор;
- дополнительные датчики;
- внешние кнопки.

Они могут потребоваться в следующих лабораторных работах.

# 2. Blue Pill

В текущем учебном треке используется:

```text
Blue Pill
STM32F103C8T6
```

![Blue Pill](images/38_bluepill_board.jpg)

Blue Pill — компактная плата на микроконтроллере STM32.

В рамках курса она используется как основной учебный стенд.

---

## Что необходимо проверить при покупке

На микроконтроллере должна быть маркировка:

```text
STM32F103C8T6
```

Для текущего курса важно приобрести именно плату на STM32F103C8T6, так как:

- инструкции создаются для этого микроконтроллера;
- используется пакет STM32CubeF1;
- первый проект настроен под STM32F103C8T6;
- примеры курса проверяются на этой конфигурации.

Подробная информация:

➡️ **[Blue Pill STM32F103C8T6](../../resources/hardware/blue-pill-stm32f103/README.md)**

# 3. ST-LINK V2

Для программирования микроконтроллера используется:

```text
ST-LINK V2
```

![ST-LINK V2](images/39_stlink_v2.jpg)

ST-LINK позволяет:

- записывать программу во Flash-память STM32;
- запускать программу;
- выполнять отладку;
- работать с микроконтроллером через интерфейс SWD.

Для первой лабораторной работы достаточно обычного ST-LINK V2.

---

# 4. Как Blue Pill и ST-LINK используются вместе

Плата и программатор выглядят примерно так:

![Blue Pill и ST-LINK V2](images/40_bluepill_stlink_setup.jpg)

Для интерфейса SWD используются четыре основных сигнала:

| ST-LINK V2 | Blue Pill |
|---|---|
| 3.3V | 3.3V |
| GND | GND |
| SWDIO | SWDIO |
| SWCLK | SWCLK |

Подробное подключение будет выполнено в лабораторной работе №1.

---

## Важно

Перед подключением необходимо ориентироваться **по маркировке контактов**, а не только по расположению выводов.

У разных исполнений ST-LINK V2 расположение контактов может отличаться.

Не подключайте вывод:

```text
5V
```

программатора к контакту:

```text
3.3V
```

платы.

# 10. Установка STM32CubeMX

Начнём с STM32CubeMX.

Распакуйте:

```text
SetupSTM32CubeMX-6.18.1-Win-x86_64.zip
```

и запустите установщик.

---

## 10.1. Режим установки

В проверенной конфигурации рекомендуется выбрать:

```text
Install for all users
```

![Режим установки STM32CubeMX](images/01_cubemx_install_mode.jpg)

### Почему

При тестировании варианта:

```text
Install for me only
```

STM32CubeMX был установлен в пользовательский каталог Windows.

На тестовом компьютере после этого появилась проблема с запуском встроенной Java Runtime Environment.

Установка:

```text
Install for all users
```

в стандартный системный путь проблему устранила.

Это не означает, что ошибка обязательно возникнет на каждом компьютере, но для курса используется проверенный вариант.

# 15. Возможная ошибка Java Runtime Environment

На одном из проверенных вариантов установки появилось сообщение:

![Ошибка Java Runtime Environment](images/08_cubemx_jre_error.jpg)

При этом встроенная Java физически присутствовала в каталоге программы.

На тестовой системе помогло:

1. удалить пользовательскую установку;
2. снова запустить установщик;
3. выбрать:
   ```text
   Install for all users
   ```
4. использовать стандартный системный путь;
5. запустить STM32CubeMX повторно.

После этого программа работала штатно.

# 18. Installed Version и Available Version

В менеджере пакетов могут отображаться две разные версии:

```text
Installed Version
```

и:

```text
Available Version
```

Для offline-работы важно именно:

```text
Installed Version
```

В текущем курсе используется:

```text
STM32CubeF1 v1.8.0
```

Даже если STM32CubeMX знает о существовании более новой версии, автоматически скачивать её не требуется.

# 35. Что пока не нужно делать

На подготовительном этапе пока **не нужно**:

- создавать проект STM32F103C8T6;
- настраивать PC13;
- писать Blink;
- изменять Clock Tree;
- компилировать программу;
- прошивать микроконтроллер.

Это выполняется в:

➡️ **[Лабораторной работе №1 — Blink](../01-blink/README.md)**

Перед переходом к первой лабораторной работе проверьте каждый пункт.

## Оборудование

- [ ] есть Blue Pill;
- [ ] на плате используется STM32F103C8T6;
- [ ] есть ST-LINK V2;

## STM32CubeIDE

- [ ] STM32CubeIDE 2.2.0 установлен;
- [ ] STM32CubeIDE запускается;
- [ ] ST-LINK drivers установлены;

# Лабораторная работа №1

## Создание первого проекта STM32 и управление GPIO — Blink

В первой лабораторной работе вы:

- выберете STM32F103C8T6;
- включите SWD;
- настроите PC13;
- создадите проект;
- познакомитесь со структурой проекта;
- напишете программу на HAL;
- выполните Build;
- подключите ST-LINK;
- прошьёте STM32;
- получите первый физический результат.

Ожидаемый результат:

```text
5 миганий
→ пауза 2 секунды
→ повтор
```
