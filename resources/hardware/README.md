Этот раздел определяет **минимальный комплект**, необходимый для текущего проверенного трека STM32 Start Lab, и даёт практические ориентиры по покупке.

Актуальность карточек и наличия проверялась: **16.10.2026**.

Текущий трек:

```text
Windows
→ Blue Pill STM32F103C8T6
→ ST-LINK V2
→ SWD
→ ЛР №1
```

## Минимальный комплект

| Позиция | Количество | Статус |
|---|---:|---|
| Blue Pill на STM32F103C8T6 | 1 | обязательно |
| ST-LINK V2 / совместимый программатор с SWD | 1 | обязательно |
| Провода Dupont Female–Female | не менее 4 | обязательно, если не входят в комплект ST-LINK |
| USB-подключение ST-LINK к ПК | 1 | обязательно |

Для ЛР №1 **не требуются** макетная плата, внешний LED, резисторы, USB-UART, логический анализатор и датчики.

# 1. Blue Pill STM32F103C8T6

Для точного повторения курса требуется плата с микроконтроллером:

```text
STM32F103C8T6
```

## Что проверить перед покупкой

Обязательно проверьте:

- на фотографии микроконтроллера читается `STM32F103C8T6`;
- это не `CKS32F103...`, `GD32F103...` и не другой совместимый MCU;
- доступны `SWDIO`, `SWCLK`, `3.3V`, `GND`;
- имеется `BOOT0`;
- желательно, чтобы контактные гребёнки уже были припаяны;
- в отзывах есть фотографии реальной платы.

> Для курса важна не надпись «Blue Pill» в карточке товара, а **фактическая маркировка STM32F103C8T6 на микроконтроллере**.

Подробная аппаратная карточка:

➡️ **[Blue Pill — STM32F103C8T6](blue-pill-stm32f103/README.md)**

## Что проверить в карточке ST-LINK

До заказа убедитесь:

- явно указана поддержка STM32 и SWD;
- имеются `SWDIO` и `SWCLK`;
- доступен `3.3V`;
- есть фотографии маркировки выводов;
- есть отзывы о работе именно с STM32;
- в комплекте указаны провода, если вы рассчитываете на них.

Расположение контактов у совместимых ST-LINK может отличаться. В курсе всегда используется **маркировка сигнала**, а не «номер контакта по фотографии».

# 4. Практический выбор — что заказать студенту

## Минимальный заказ

```text
1 × Blue Pill STM32F103C8T6
1 × ST-LINK V2 Mini с SWD
1 × Dupont Female–Female 40 шт / 20 см
```

Если ST-LINK уже комплектуется подходящими Dupont-проводами:

```text
1 × Blue Pill STM32F103C8T6
1 × ST-LINK V2 Mini + кабель Dupont
```

этого достаточно для ЛР №1.

## Что я бы выбрал для курса

Приоритет выбора:

```text
1. точное соответствие STM32F103C8T6
2. фотографии реального товара
3. отзывы с фотографиями
4. припаянные контактные гребёнки
5. ST-LINK с подписанными SWDIO/SWCLK/3.3V/GND
6. комплект проводов
7. цена
```

Количество отзывов **не должно перевешивать несовпадение микроконтроллера**.

# 5. Если конкретная карточка исчезла

Карточки маркетплейсов меняются. Если одна из ссылок больше не открывается, используйте поиск по точной фразе:

```text
STM32F103C8T6 Blue Pill
```

и для программатора:

```text
ST-LINK V2 STM32 SWD
```

Для проводов:

```text
Dupont Female Female 20cm 40
```

После этого примените чек-лист из этого раздела. **Не заменяйте STM32F103C8T6 на совместимый MCU только потому, что карточка имеет больше отзывов.**

---

# 6. USB-подключение

Тип подключения зависит от исполнения ST-LINK.

Многие ST-LINK V2 Mini имеют встроенный USB-A штекер и отдельный кабель им не требуется.

Если выбранный программатор имеет отдельный USB-разъём, используйте соответствующий **кабель передачи данных**, а не кабель только для питания.

---

# 7. Что пока не покупать

До появления соответствующей лабораторной работы не требуется специально закупать:

- внешний LED;
- набор резисторов;
- кнопки;
- USB-UART преобразователь;
- логический анализатор;
- датчики I2C/SPI;
- дополнительные STM32-платы.

Комплект расширяется только тогда, когда новое оборудование становится частью утверждённой лабораторной работы.

---

# 8. Проверка комплекта перед началом курса

Перед ЛР №1 требуется убедиться:

- [ ] на Blue Pill читается `STM32F103C8T6`;
- [ ] доступны `SWDIO`, `SWCLK`, `3.3V`, `GND`;
- [ ] имеется ST-LINK V2 / совместимый SWD-программатор;
- [ ] на программаторе определены `SWDIO`, `SWCLK`, `3.3V`, `GND`;
- [ ] имеются четыре подходящих провода;
- [ ] ST-LINK можно подключить к USB компьютера.
