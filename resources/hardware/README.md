## Пример стартового комплекта

Ниже приведены примеры товаров, которые можно использовать для начала курса.

> Ссылки являются примерами, а не обязательными местами покупки.
> Ассортимент, цена, продавец и фактическая комплектация могут изменяться.
> Студент самостоятельно проверяет соответствие товара требованиям курса перед заказом.

### 1. Blue Pill

Пример:
https://www.ozon.ru/product/1425852265/

Требование курса:

STM32F103C8T6

Важно: в карточке могут предлагаться варианты на STM32F103C8T6,
CKS32F103C8T6 или GD32F103C8T6.

Для полного соответствия учебному курсу необходимо выбрать именно STM32F103C8T6.

Перед покупкой проверить:
- маркировку MCU;
- наличие выводов SWDIO и SWCLK;
- наличие 3.3V и GND;
- наличие BOOT0;
- комплектность платы.

### 2. ST-LINK V2

Пример:
https://www.ozon.ru/product/1018533065/

Перед покупкой проверить наличие:
- SWDIO;
- SWCLK;
- GND;
- 3.3V;
- USB-подключения.

### 3. Провода Dupont

Пример:
https://www.ozon.ru/product/1920135038/

Набор содержит несколько типов проводов и подходит не только для ЛР №1,
но и для последующих лабораторных работ.

Для первой работы необходимо минимум четыре подходящих провода.
