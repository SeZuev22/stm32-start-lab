# Оборудование и закупка

[← Ресурсы](../README.md) | [↑ Учебный курс](../../course/README.md) | [ЛР №1](../../course/01-blink/README.md)

## Назначение раздела

Здесь приведены требования к стартовому комплекту STM32 Start Lab и примеры товаров, с которых можно начать поиск.

Ссылки на маркетплейсы являются **ориентирами**, а не обязательными местами покупки и не гарантией качества конкретного экземпляра. Цена, продавец, рейтинг, комплектация и сама карточка товара могут изменяться.

Перед заказом студент самостоятельно проверяет соответствие товара техническим требованиям курса.

## Минимальный комплект для ЛР №1

| Позиция | Требование | Количество |
|---|---|---:|
| Отладочная плата | Blue Pill с STM32F103C8T6 | 1 |
| Программатор | ST-LINK V2 / совместимый SWD | 1 |
| Провода | Dupont, подходящие к контактам платы и программатора | не менее 4 |
| USB | Кабель/разъём для подключения ST-LINK к ПК | 1 |
| ПК | Windows, права на установку ПО | 1 |

Макетная плата, внешний LED, резисторы, датчики и логический анализатор для первой работы не требуются.

## 1. Blue Pill STM32F103C8T6

Пример карточки Ozon:

https://www.ozon.ru/product/1425852265/

### Обязательное требование

Для текущего курса требуется:

```text
STM32F103C8T6
```

В указанной карточке в названии перечисляются также CKS32F103C8T6 и GD32F103C8T6. Поэтому её следует рассматривать только как пример места покупки.

**Если продавец не позволяет однозначно выбрать или подтвердить STM32F103C8T6, лучше выбрать другую карточку.**

Перед покупкой необходимо проверить:

- маркировку микроконтроллера `STM32F103C8T6`;
- наличие выводов `SWDIO` и `SWCLK`;
- наличие `3.3V` и `GND`;
- наличие `BOOT0`;
- наличие штырьковых контактов либо возможность их установки;
- фактическую комплектацию товара.

Подробная аппаратная карточка:

**[Blue Pill STM32F103C8T6](blue-pill-stm32f103/README.md)**

## 2. ST-LINK V2

Пример карточки Ozon:

https://www.ozon.ru/product/1018533065/

Перед покупкой проверьте наличие сигналов:

```text
SWDIO
SWCLK
GND
3.3V
```

Расположение контактов у совместимых ST-LINK V2 может отличаться, поэтому при подключении необходимо ориентироваться по маркировке сигналов, а не по положению контакта на корпусе.

Подробная аппаратная карточка:

**[ST-LINK V2](st-link/README.md)**

## 3. Провода Dupont

Пример набора Ozon:

https://www.ozon.ru/product/1920135038/

Набор содержит несколько типов проводов и подходит для развития лабораторного стенда.

Для ЛР №1 необходимо минимум четыре провода, позволяющих соединить:

| ST-LINK | Blue Pill |
|---|---|
| 3.3V | 3.3V |
| GND | GND |
| SWDIO | SWDIO |
| SWCLK | SWCLK |

## Можно ли купить готовый набор

Да. Если найден комплект вида:

```text
Blue Pill STM32F103C8T6
+ ST-LINK
+ Dupont
```

его можно использовать при одновременном выполнении двух условий:

1. в комплекте гарантирован именно STM32F103C8T6;
2. итоговая цена и комплектация разумнее покупки отдельных позиций.

Наличие слова `Blue Pill` само по себе не подтверждает модель установленного микроконтроллера.

## Как выбирать между несколькими предложениями

Приоритет рекомендуется задавать в таком порядке:

```text
соответствие MCU
→
понятная комплектация
→
репутация продавца и отзывы
→
срок доставки
→
цена
```

Самая дешёвая карточка не является автоматически лучшим вариантом, если модель MCU указана неоднозначно.

## Оборудование следующих лабораторных работ

Стартовый комплект предназначен только для первого этапа курса.

Для каждой следующей лабораторной работы в её README отдельно указывается:

- что уже должно быть у студента;
- что потребуется дополнительно;
- какие характеристики важны;
- требуется ли новая закупка;
- примеры совместимых товаров, если это действительно необходимо.

Студенту не требуется заранее закупать оборудование для всего семестра.

## Электрическая безопасность стенда

Работы текущего трека выполняются на низковольтном учебном оборудовании.

Не подключайте вывод `5V` программатора к контакту `3.3V` платы. GPIO STM32 не предназначен для прямого подключения промышленной нагрузки или сетевого напряжения.

## Контроль перед ЛР №1

- [ ] на MCU читается `STM32F103C8T6`;
- [ ] есть ST-LINK V2 / совместимый SWD-программатор;
- [ ] есть четыре подходящих провода;
- [ ] доступны `3.3V`, `GND`, `SWDIO`, `SWCLK`;
- [ ] ST-LINK подключается к USB компьютера.
