# Оборудование и закупка

---

Этот раздел определяет **минимальный комплект**, необходимый для текущего проверенного трека STM32 Start Lab.

Текущий трек:

```text
Windows
→ Blue Pill STM32F103C8T6
→ ST-LINK V2
→ SWD
→ ЛР №1
```

## Что требуется приобрести

| Позиция | Количество | Статус |
|---|---:|---|
| Blue Pill на STM32F103C8T6 | 1 | обязательно |
| ST-LINK V2 / совместимый программатор с SWD | 1 | обязательно |
| Провода Dupont | не менее 4 | обязательно |
| USB-подключение ST-LINK к ПК | 1 | обязательно |

Отдельная макетная плата, внешний LED, резисторы и дополнительные датчики для ЛР №1 не требуются.

---

# 1. Blue Pill STM32F103C8T6

Для точного повторения курса требуется плата с микроконтроллером:

```text
STM32F103C8T6
```

При выборе товара проверяйте:

- фотографию самой платы;
- маркировку основного микроконтроллера;
- наличие выводов `SWDIO`, `SWCLK`, `3.3V`, `GND`;
- наличие `BOOT0`;
- состояние контактных гребёнок: припаяны они или входят в комплект;
- отзывы покупателей с реальными фотографиями.

Не выбирайте плату только по словам `Blue Pill` в названии товара: под этим названием продаются разные совместимые платы.

Подробная карточка:

➡️ **[Blue Pill — STM32F103C8T6](blue-pill-stm32f103/README.md)**

### Где искать

Подходящие платы обычно продаются на:

- Ozon;
- Wildberries;
- AliExpress;
- в магазинах электронных компонентов.

Используйте поисковую фразу:

```text
STM32F103C8T6 Blue Pill
```

Маркировку товара требуется проверить до заказа.

---

# 2. ST-LINK V2

Для текущего курса требуется программатор, поддерживающий SWD и имеющий доступные сигналы:

```text
3.3V
GND
SWDIO
SWCLK
```

При выборе проверяйте:

- наличие подписей выводов на корпусе или плате;
- поддержку STM32 / SWD;
- наличие USB-разъёма или встроенного USB-штекера;
- отзывы с фотографиями;
- отсутствие требования использовать нестандартное программное обеспечение.

Подробная карточка:

➡️ **[ST-LINK V2 — подключение Blue Pill](st-link/README.md)**

### Где искать

Подходящие программаторы обычно продаются на тех же маркетплейсах и в магазинах электронных компонентов.

Поисковая фраза:

```text
ST-LINK V2 STM32 SWD
```

У совместимых ST-LINK расположение контактов может различаться, поэтому после покупки всегда ориентируйтесь по маркировке сигналов.

---

# 3. Провода Dupont

Для соединения Blue Pill со ST-LINK требуется не менее четырёх проводов.

Тип проводов зависит от контактов конкретной платы и программатора. Для распространённой конфигурации с штырьковыми выводами удобно иметь комплект:

```text
Female-Female
Male-Female
Male-Male
```

Для первой лабораторной достаточно четырёх подходящих проводов.

Поисковая фраза:

```text
Dupont jumper wires 2.54 mm
```

---

# 4. USB-подключение

Тип подключения зависит от конкретного исполнения ST-LINK.

Многие совместимые ST-LINK V2 имеют встроенный USB-A штекер и отдельный кабель им не требуется.

Если выбранный программатор имеет USB-разъём вместо встроенного штекера, требуется соответствующий **кабель передачи данных**, а не кабель только для питания.

---

# 5. Что пока не покупать

До появления соответствующей лабораторной работы не требуется специально закупать:

- внешний LED;
- набор резисторов;
- кнопки;
- USB-UART преобразователь;
- логический анализатор;
- датчики I2C/SPI;
- дополнительные платы STM32.

Комплект курса расширяется только тогда, когда новое оборудование становится частью утверждённой лабораторной работы.

---

# 6. Проверка комплекта перед началом курса

До начала ЛР №1 требуется убедиться:

- [ ] на Blue Pill установлен STM32F103C8T6;
- [ ] на плате доступны `SWDIO`, `SWCLK`, `3.3V`, `GND`;
- [ ] имеется ST-LINK V2 / совместимый SWD-программатор;
- [ ] на программаторе определены `SWDIO`, `SWCLK`, `3.3V`, `GND`;
- [ ] имеются четыре подходящих провода;
- [ ] ST-LINK можно подключить к USB компьютера.

После проверки переходите к:
