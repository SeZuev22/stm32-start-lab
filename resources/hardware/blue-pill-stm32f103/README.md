# 1. Что такое Blue Pill

**Blue Pill** — компактная отладочная плата на базе микроконтроллера семейства STM32.

В текущем учебном курсе используется плата с микроконтроллером:

```text
STM32F103C8T6
```

![Blue Pill](../../../course/00-getting-started/images/38_bluepill_board.jpg)

Blue Pill используется в STM32 Start Lab как основной учебный стенд для первых лабораторных работ.

---

# 2. Почему используется Blue Pill

Для первого знакомства с STM32 эта плата удобна тем, что позволяет изучать:

- GPIO;
- внешние прерывания;
- таймеры;
- PWM;
- ADC;
- UART;
- SPI;
- I2C;
- другие периферийные устройства STM32.

При этом для первой лабораторной работы дополнительная периферия практически не требуется.

Достаточно:

```text
Blue Pill
+
ST-LINK V2
+
4 соединительных провода
```

Первый результат можно получить на встроенном светодиоде платы.

---

# 3. Микроконтроллер

В текущем курсе используется:

```text
STM32F103C8T6
```

Это микроконтроллер семейства:

```text
STM32F1
```

на процессорном ядре:

```text
Arm Cortex-M3
```

Для работы с ним в STM32CubeMX используется MCU Package:

```text
STM32CubeF1
```

В проверенной конфигурации курса:

```text
STM32CubeF1 v1.8.0
```


# 6. Встроенный светодиод

На используемом и проверенном экземпляре Blue Pill встроенный пользовательский светодиод связан с выводом:

```text
PC13
```

В лабораторной работе №1 PC13 используется как цифровой выход для встроенного диагностического LED.

---

# 7. Что означает PC13

Обозначение:

```text
PC13
```

состоит из двух частей.

```text
PC
```

означает:

```text
порт GPIO C
```

а:

```text
13
```

означает:

```text
вывод №13 этого порта
```

То есть PC13 — это 13-й вывод GPIO-порта C.

В программе он может быть представлен как:

```c
GPIOC
GPIO_PIN_13
```

Но в STM32CubeMX мы присваиваем ему пользовательскую метку:

```text
LED
```

После этого в коде автоматически появляются более понятные обозначения:

```c
LED_GPIO_Port
LED_Pin
```

---

# 8. Что такое GPIO

GPIO расшифровывается как:

```text
General Purpose Input/Output
```

То есть:

```text
цифровой вход/выход общего назначения
```

Вывод GPIO можно программно использовать в разных режимах.

Например:

```text
Input
Output
Alternate Function
Analog
```

В лабораторной работе №1 используется:

```text
PC13 → GPIO_Output
```

Это позволяет программе изменять логический уровень на выводе и управлять светодиодом.

---

# 9. Active-low LED

На используемой Blue Pill встроенный светодиод работает по принципу:

```text
active-low
```

Это означает:

```text
логический 0 → LED включён
логическая 1 → LED выключен
```

Поэтому команда:

```c
HAL_GPIO_WritePin(LED_GPIO_Port, LED_Pin, GPIO_PIN_RESET);
```

включает светодиод.

А:

```c
HAL_GPIO_WritePin(LED_GPIO_Port, LED_Pin, GPIO_PIN_SET);
```

выключает его.

---

# 10. Почему это кажется обратным

Интуитивно начинающий программист может ожидать:

```text
1 → включено
0 → выключено
```

Но электрическая схема может быть устроена иначе.

При active-low нагрузка активируется при низком логическом уровне.

Поэтому программное состояние GPIO необходимо связывать не с названием `SET` или `RESET`, а с реальной электрической схемой.

Это важный принцип при работе с микроконтроллерами.

---

# 11. Интерфейс SWD

Для программирования Blue Pill в курсе используется:

```text
SWD
```

Полное название:

```text
Serial Wire Debug
```

Основные сигналы:

```text
SWDIO
SWCLK
```

Дополнительно необходимы:

```text
GND
3.3V
```

---

# 12. SWDIO

```text
SWDIO
```

используется для передачи данных между:

```text
ST-LINK
↔
STM32
```

---

# 13. SWCLK

```text
SWCLK
```

является тактовой линией интерфейса SWD.

Она используется ST-LINK для синхронизации обмена с микроконтроллером.

---

# 14. SWD в STM32CubeMX

В проекте интерфейс включается:

```text
System Core
→ SYS
→ Debug
→ Serial Wire
```

После этого STM32CubeMX резервирует:

```text
PA13 → SWDIO
PA14 → SWCLK
```

![Настройка Serial Wire](../../../course/00-getting-started/images/26_sys_serial_wire.jpg)

---

# 15. Почему SWD нужно включать явно

Если выводы интерфейса отладки использовать как обычные GPIO, работа ST-LINK может быть нарушена.

Поэтому в учебных проектах интерфейс программирования резервируется явно:

```text
Serial Wire
```

Так студент понимает, какие выводы используются для связи с программатором.

---

# 16. Подключение ST-LINK V2

Для первой лабораторной работы используется следующее соединение:

| ST-LINK V2 | Blue Pill |
|---|---|
| 3.3V | 3.3V |
| GND | GND |
| SWDIO | SWDIO |
| SWCLK | SWCLK |

Проверенная конфигурация:

![Blue Pill и ST-LINK V2](../../../course/00-getting-started/images/40_bluepill_stlink_setup.jpg)

# 17. Важное правило подключения

У различных исполнений и клонов ST-LINK расположение выводов может отличаться.

Поэтому ориентируйтесь по надписям:

```text
3.3V
GND
SWDIO
SWCLK
```

а не только по положению контакта на корпусе.

---

# 18. Питание

Для используемого учебного подключения применяются:

```text
3.3V
GND
```

Перед подключением обязательно проверьте маркировку контактов.

Не подключайте вывод:

```text
5V
```

ST-LINK к контакту:

```text
3.3V
```

Blue Pill.

Для первой лабораторной работы используется только низковольтная часть учебного стенда.

---

# 19. BOOT0

На Blue Pill имеется настройка:

```text
BOOT0
```

Она влияет на выбор источника загрузки микроконтроллера после сброса.

Для обычного запуска пользовательской программы из внутренней Flash-памяти в лабораторной работе используется:

```text
BOOT0 = 0
```

---

# 20. Зачем нужен BOOT0

STM32 может запускаться из разных областей памяти.

Для обычной работы после прошивки нам необходимо, чтобы выполнялась программа пользователя из Flash.

Поэтому в стандартном режиме первой лабораторной:

```text
BOOT0 = 0
```

Если прошивка прошла успешно, но после перезапуска программа не выполняется, положение BOOT0 является одним из пунктов проверки.

---

# 21. Что пока не требуется настраивать

В лабораторной работе №1 не требуется специально изменять:

```text
Clock Configuration
```

Цель первой работы — освоить самый короткий полный маршрут:

```text
GPIO
→ код
→ Build
→ ST-LINK
→ Flash
→ результат
```

Настройка системы тактирования будет изучаться тогда, когда она действительно потребуется для соответствующей лабораторной работы.

---

# 22. STM32CubeMX и Blue Pill

Blue Pill является сторонней платой.

Поэтому в STM32CubeMX используется:

```text
MCU Selector
```

а не:

```text
Board Selector
```

В поиске выбирается непосредственно:

```text
STM32F103C8T6
```

![STM32F103C8T6 в MCU Selector](../../../course/00-getting-started/images/25_mcu_selector_f103c8t6.jpg)

---

# 23. Почему выбирается именно микроконтроллер

STM32CubeMX знает характеристики самого STM32F103C8T6:

- периферию;
- GPIO;
- память;
- тактирование;
- альтернативные функции.

Но Blue Pill — это плата стороннего производителя.

Поэтому некоторые особенности платы, например подключение встроенного LED к PC13, необходимо учитывать отдельно.

# 25. Начальный уровень GPIO

В проверенном проекте задаётся:

```text
GPIO output level:
High
```

Причина:

```text
LED active-low
```

Поэтому:

```text
High
```

соответствует выключенному LED при запуске программы.
