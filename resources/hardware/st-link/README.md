# Подключение ST-LINK V2

В этом разделе рассматривается подключение программатора ST-LINK V2 к платам STM32.

ST-LINK используется для:

- прошивки микроконтроллера;
- отладки программы;
- подключения к микроконтроллеру по интерфейсу SWD.

## Интерфейс SWD

Для базовой работы обычно используются следующие сигналы:

- SWDIO;
- SWCLK;
- GND;
- питание / опорное напряжение платы.

Точная схема подключения будет отдельно проверена для:

- Blue Pill — STM32F103C8T6;
- Black Pill — STM32F411CEU6.

## Общий порядок подключения

1. Отключить питание платы.
2. Соединить ST-LINK V2 с выводами SWD платы.
3. Проверить соответствие сигналов.
4. Подключить ST-LINK к компьютеру.
5. Проверить определение программатора в системе.
6. Проверить связь с микроконтроллером.
7. Выполнить прошивку.

## Важно

Перед подключением необходимо проверить маркировку конкретного ST-LINK V2 и конкретной платы.

Расположение выводов у различных клонов и ревизий может отличаться.

Поэтому в учебном пособии будут приведены отдельные проверенные схемы подключения для каждой используемой платы.

## Программное обеспечение

Для работы со ST-LINK будут использоваться:

- STM32CubeIDE;
- ST-LINK Driver;
- STM32CubeProgrammer — как дополнительный инструмент диагностики.

## Что будет добавлено после проверки

- фотография программатора;

- схема соединений;

- проверка определения ST-LINK в Windows;

- проверка подключения к Black Pill;
