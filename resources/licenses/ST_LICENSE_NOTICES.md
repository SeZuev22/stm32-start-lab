# Лицензионные уведомления STMicroelectronics

[← Resources](../README.md) | [↑ На главную](../../README.md)

---

Этот раздел относится к стороннему программному обеспечению и компонентам STMicroelectronics, используемым в STM32 Start Lab.

STM32 Start Lab является независимым учебным проектом и **не является официальным продуктом STMicroelectronics**.

## Компоненты текущего учебного трека

В курсе используются:

```text
STM32CubeMX 6.18.1
STM32CubeIDE 2.2.0
STM32CubeF1 v1.8.0
HAL / CMSIS
```

В GitHub Release `v0.2` в текущей версии проекта присутствуют архивы программного обеспечения, используемые в учебном маршруте. Право публичного перераспространения каждого стороннего пакета должно оцениваться по его действующему лицензионному соглашению; сохранение notices само по себе не создаёт такого права.

## Основной принцип работы со сторонними пакетами

При работе с исходными пакетами STMicroelectronics требуется сохранять содержащиеся в них:

- copyright notices;
- license files;
- disclaimers;
- third-party notices;
- сведения об open-source компонентах.

Не следует удалять или изменять эти материалы. Если лицензия конкретного пакета не разрешает публичное перераспространение, в репозитории следует оставлять официальную ссылку на загрузку, а не копию установщика.

## ST_LICENSES.zip

В Release также размещается:

```text
ST_LICENSES.zip
```

Этот архив является дополнительным индексом и уведомлением для учебного комплекта. Он **не заменяет** юридические файлы, входящие в оригинальные пакеты STMicroelectronics.

## Сгенерированный проект STM32

Каталог:

```text
course/01-blink/project/
```

содержит сгенерированные STM32CubeMX файлы, HAL/CMSIS и пользовательский код лабораторной работы.

Лицензионные файлы и уведомления, поставляемые вместе с используемыми компонентами, должны сохраняться.

## Товарные знаки

STM32, STM32Cube, STM32CubeMX, STM32CubeIDE и связанные названия принадлежат соответствующим правообладателям.

Использование этих названий в STM32 Start Lab служит исключительно для идентификации применяемых инструментов и компонентов.
