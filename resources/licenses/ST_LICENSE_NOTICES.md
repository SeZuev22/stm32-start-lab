# Основные документы

| Документ | Тип | Для чего используется в курсе |
|---|---|---|
| DS5319 | Datasheet | характеристики STM32F103x8/xB, выводы, корпус |
| RM0008 | Reference Manual | GPIO, RCC и дальнейшая периферия STM32F1 |
| PM0056 | Programming Manual | ядро Cortex-M3, NVIC, системная архитектура |

| AN2586 | Application Note | питание, Boot, Reset, отладка, аппаратные основы |

| UM2563 | Installation Guide | установка STM32CubeIDE |
| UM2553 | Quick Start Guide | базовая работа в STM32CubeIDE |
| UM2609 | User Guide | Workspace, Build, Run, Debug |

# Что требуется знать для ЛР №1

## DS5319

Для Blink достаточно понимать:

- используется STM32F103C8T6;
- MCU относится к STM32F1;
- корпус используемого MCU — LQFP48;
- PC13 является выводом микроконтроллера;
- PA13/PA14 используются для SWD.

## RM0008

Для первой работы требуется общее понимание:

```text
GPIO
RCC
```

STM32CubeMX и HAL скрывают большую часть регистровой настройки, но студент должен понимать, что GPIO является периферийным блоком микроконтроллера.

## UM1850

В первой лабораторной используются:

```c
HAL_GPIO_WritePin()
HAL_GPIO_TogglePin()
HAL_Delay()
```

`HAL_GPIO_WritePin()` задаёт конкретное состояние вывода.

`HAL_GPIO_TogglePin()` инвертирует текущее состояние.

## AN2586

К первой работе относятся:

- питание;
- Boot;
- Reset;
- интерфейс программирования и отладки.

## UM1075

К работе относятся понятия:

```text
ST-LINK V2
SWD
SWDIO
SWCLK
GND
3.3V
```

# Как курс использует первоисточники

Методика STM32 Start Lab:

```text
тема лабораторной
↓
необходимый минимум теории объясняется в самой ЛР
↓
указывается официальный документ-первоисточник
↓
оригинал открывается только при необходимости углубления
```

Таким образом студент не должен прерывать основной маршрут и самостоятельно искать нужные страницы в больших руководствах.

# Datasheet, Reference Manual и HAL Manual — разница

```text
Datasheet
→ что есть у конкретного MCU и какие у него характеристики
```

```text
Reference Manual
→ как работают внутренние периферийные блоки
```

```text
Programming Manual
→ как устроено процессорное ядро
```

```text
HAL/LL Manual
→ какие программные функции предоставляют библиотеки ST
```

```text
Application Note
→ инженерные рекомендации по отдельной теме
```
