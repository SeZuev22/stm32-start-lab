Справочные материалы STM32 Start Lab.

- **[ST-LINK V2](hardware/st-link/README.md)** — SWD и подключение;
- **[Документация и первоисточники](references/README.md)** — назначение DS5319, RM0008, UM1850 и других документов;
- **[Программное обеспечение](software/README.md)** — проверенные версии и Release;
- `licenses/` — лицензионные уведомления;
- `software/checksums/` — SHA-256 контрольные суммы.
