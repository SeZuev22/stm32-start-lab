# Resources

Справочный раздел STM32 Start Lab. Для прохождения курса не требуется изучать его последовательно: обязательные ссылки приводятся непосредственно в подготовительном разделе и лабораторных работах.

## Разделы

- **[Оборудование и закупка](hardware/README.md)** — минимальный комплект, критерии выбора и примеры товаров;
- **[Blue Pill STM32F103C8T6](hardware/blue-pill-stm32f103/README.md)** — аппаратная карточка платы;
- **[ST-LINK V2](hardware/st-link/README.md)** — SWD, назначение программатора и подключение;
- **[Учебные материалы и первоисточники](references/README.md)** — бесплатные русскоязычные и зарубежные ресурсы, а также официальная документация;
- **[Программное обеспечение](software/README.md)** — проверенные версии и состав Release;
- **[Лицензионные уведомления](licenses/ST_LICENSE_NOTICES.md)** — сведения о сторонних компонентах;
- `software/checksums/` — контрольные суммы SHA-256.
