# Официальная документация

В этом разделе собраны ссылки на официальную документацию, используемую в учебном курсе STM32 Start Lab.

Текущий учебный трек:

**Blue Pill → STM32F103C8T6**

Студенту не требуется читать все документы целиком.

В каждой лабораторной работе будет отдельно указано:

- какой документ необходимо открыть;
- какой раздел потребуется;
- что именно в нём искать;
- зачем этот документ нужен.

## Основные документы

### DS5319

Datasheet для микроконтроллеров STM32F103x8/xB.

Используется для:

- изучения выводов микроконтроллера;
- характеристик памяти;
- электрических параметров;
- назначения периферийных выводов.

### RM0008

Reference Manual для семейства STM32F1.

Используется для изучения:

- GPIO;
- RCC;
- таймеров;
- ADC;
- USART;
- SPI;
- I2C;
- другой периферии.

### PM0056

Programming Manual для ядра Arm Cortex-M3.

Используется для более глубокого изучения архитектуры процессорного ядра.

### UM1850

Руководство по HAL и LL для STM32F1.

Используется для понимания функций HAL, применяемых в лабораторных работах.

### AN2586

Руководство по аппаратной разработке на STM32F10xxx.

Полезно для изучения:

- питания;
- Reset;
- Boot;
- тактирования;
- интерфейсов программирования и отладки.

---

Для каждой лабораторной работы необходимые документы будут указаны непосредственно в её инструкции.
