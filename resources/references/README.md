# Зачем нужен этот раздел

При работе с микроконтроллерами важно уметь пользоваться не только готовыми примерами, но и официальной технической документацией.

В этом разделе собраны документы, которые используются в учебном курсе **STM32 Start Lab**.

Текущий проверенный учебный трек:

```text
Blue Pill
→ STM32F103C8T6
→ ST-LINK V2
→ STM32CubeMX
→ STM32CubeIDE
→ HAL
```

Студенту **не требуется читать все документы полностью**.

Для каждой лабораторной работы отдельно указывается:

```text
какой документ нужен
↓
что в нём искать
↓
зачем это требуется
```

---

# 1. Документация STM32F103

Основной микроконтроллер текущего курса:

```text
STM32F103C8T6
```

Для работы с ним используются несколько разных типов документации.

Важно понимать, что Datasheet, Reference Manual и Programming Manual — это не одно и то же.

---

# 2. DS5319 — Datasheet STM32F103x8/xB

## Что это

Datasheet содержит основные характеристики конкретной группы микроконтроллеров STM32F103.

Для STM32F103C8T6 это один из основных документов.

## Что в нём искать

Документ используется для изучения:

- характеристик микроконтроллера;
- объёма памяти;
- корпуса;
- назначения выводов;
- альтернативных функций выводов;
- электрических характеристик;
- допустимых режимов работы;
- основных параметров периферии.

## Когда он понадобится

### Лабораторная работа №1

В первой работе Datasheet помогает понять:

- какой микроконтроллер используется;
- что такое PC13;
- какие выводы существуют у STM32F103C8T6.

### В следующих работах

Datasheet будет использоваться при выборе:

- UART;
- SPI;
- I2C;
- ADC;
- таймеров;
- внешних выводов GPIO.

---

# 3. RM0008 — Reference Manual STM32F1

## Что это

Reference Manual описывает внутреннюю периферию микроконтроллеров семейства STM32F1.

Это один из наиболее важных документов при изучении STM32.

Если Datasheet отвечает в основном на вопрос:

```text
что есть в микроконтроллере?
```

то Reference Manual помогает понять:

```text
как это работает?
```

## Что в нём находится

RM0008 содержит описание:

- RCC;
- GPIO;
- EXTI;
- DMA;
- ADC;
- таймеров;
- USART;
- SPI;
- I2C;
- CAN;
- USB;
- Flash;
- системных функций;
- регистров периферии.

## Для лабораторной работы №1

Полностью читать RM0008 не требуется.

Для понимания Blink наиболее полезны разделы:

```text
GPIO
RCC
```

Необходимо понимать:

- зачем GPIO переводится в режим выхода;
- что такое порт GPIO;
- что такое номер вывода;
- почему периферии требуется тактирование.

---

# 4. PM0056 — Programming Manual Cortex-M3

## Что это

STM32F103 построен на процессорном ядре:

```text
Arm Cortex-M3
```

PM0056 посвящён архитектуре этого ядра.

## Что в нём рассматривается

Документ полезен для изучения:

- регистров процессора;
- модели памяти;
- исключений;
- прерываний;
- NVIC;
- системных регистров;
- архитектуры Cortex-M3.

## Нужен ли он для первой лабораторной

Для Blink подробно изучать PM0056 не требуется.

Он включён в курс как документ для дальнейшего углубления.

---

# 5. UM1850 — STM32F1 HAL и LL Drivers

## Что это

Документ описывает программные драйверы:

```text
HAL
LL
```

для семейства STM32F1.

HAL означает:

```text
Hardware Abstraction Layer
```

или:

```text
уровень аппаратной абстракции
```

## Зачем он нужен

Вместо непосредственной записи значений в регистры микроконтроллера в первых лабораторных работах используются готовые функции HAL.

Например:

```c
HAL_GPIO_WritePin()
```

## Для лабораторной работы №1

Документ помогает понять работу GPIO через HAL.

В первой работе используется:

```c
HAL_GPIO_WritePin()
```

Для начинающего студента важно сначала понять назначение функции и её аргументов.

Работа непосредственно с регистрами будет рассматриваться только тогда, когда это потребуется для понимания устройства STM32.

---

# 6. AN2586 — Hardware Development STM32F10xxx

## Что это

Application Note посвящён аппаратной части проектов на STM32F10xxx.

## Что в нём рассматривается

Документ полезен для понимания:

- питания микроконтроллера;
- Reset;
- Boot;
- тактирования;
- отладки;
- подключения программатора;
- минимальной аппаратной конфигурации.

## Почему это важно

STM32 — это не только программа.

Для корректной работы необходимо понимать связь между:

```text
аппаратной частью
+
программным обеспечением
```

В первой лабораторной это особенно связано с:

```text
ST-LINK
SWD
BOOT0
питание
```

---

# 7. UM1075 — ST-LINK/V2

## Что это

Официальное руководство STMicroelectronics по:

```text
ST-LINK/V2
```

ST-LINK используется для программирования и отладки STM32.

## Что полезно знать начинающему

Основные понятия:

- SWD;
- SWDIO;
- SWCLK;
- GND;
- питание;
- программирование;
- отладка.

## Для лабораторной работы №1

Используется интерфейс:

```text
SWD
```

Основные соединения:

```text
ST-LINK      Blue Pill

3.3V      →  3.3V
GND       →  GND
SWDIO     →  SWDIO
SWCLK     →  SWCLK
```

> Расположение выводов у неоригинальных ST-LINK может отличаться. Всегда ориентируйтесь по маркировке сигналов конкретного устройства.

# 8. Документация STM32CubeMX

STM32CubeMX используется для графической конфигурации STM32.

В курсе применяется:

```text
STM32CubeMX 6.18.1
```

Официальная документация описывает:

- создание проекта;
- MCU Selector;
- Pinout;
- GPIO;
- Clock Configuration;
- Project Manager;
- управление MCU Packages;
- генерацию кода;
- USER CODE sections.

## Для лабораторной работы №1

Наиболее важны:

```text
MCU Selector
System Core → SYS
GPIO
Project Manager
Code Generation
```

# 12. Как студент должен использовать документы

Главная ошибка начинающего — попытаться открыть Reference Manual на сотни страниц и читать его с первой страницы до последней.

В STM32 Start Lab используется другой подход.

Для каждой лабораторной работы документация применяется точечно:

```text
возникла задача
↓
определили нужную периферию
↓
нашли нужный документ
↓
открыли нужный раздел
↓
получили необходимую информацию
↓
применили её в проекте
```

# 14. Официальные источники

Используйте документацию непосредственно с официальных ресурсов:

```text
STMicroelectronics
```

Не рекомендуется использовать случайные копии Datasheet или Reference Manual из неизвестных источников, если доступна официальная версия.

Причина проста:

- документ может быть устаревшим;
- может относиться к другой ревизии;
- файл может быть неполным;
- невозможно проверить происхождение документа.
