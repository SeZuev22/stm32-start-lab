# Документация и первоисточники

[← Resources](../README.md) | [↑ Учебный курс](../../course/README.md)

---

Этот раздел показывает, **какие официальные документы лежат в основе курса** и какую роль они выполняют.

Для прохождения текущей лабораторной работы студенту **не требуется самостоятельно переходить на сайт STMicroelectronics или читать большие руководства полностью**. Необходимый минимум теории уже включён в лабораторную работу и учебное пособие.

Текущий трек:

```text
Blue Pill STM32F103C8T6
→ ST-LINK V2
→ STM32CubeMX
→ STM32CubeIDE
→ HAL
```

## Основные первоисточники

| Документ | Тип | Для чего используется в курсе |
|---|---|---|
| DS5319 | Datasheet | STM32F103x8/xB, характеристики, выводы, корпус |
| RM0008 | Reference Manual | GPIO, RCC и дальнейшая периферия STM32F1 |
| PM0056 | Programming Manual | ядро Cortex-M3, NVIC, системная архитектура |
| UM1850 | HAL/LL Manual | функции HAL для STM32F1 |
| AN2586 | Application Note | питание, Boot, Reset, аппаратные основы |
| UM1075 | User Manual | ST-LINK/V2 и SWD |
| UM2563 | Installation Guide | установка STM32CubeIDE |
| UM2553 | Quick Start Guide | базовая работа в STM32CubeIDE |
| UM2609 | User Guide | Workspace, Build, Run, Debug |

## Что требуется знать для ЛР №1

### DS5319

Для первой работы достаточно понимать:

- используется `STM32F103C8T6`;
- MCU относится к семейству STM32F1;
- PC13 является выводом микроконтроллера;
- PA13 и PA14 используются для SWD.

### RM0008

Требуется общее понимание:

```text
GPIO
RCC
```

STM32CubeMX и HAL выполняют большую часть низкоуровневой настройки автоматически, но студент должен понимать назначение GPIO как периферийного блока.

### UM1850

В ЛР №1 рассматриваются:

```c
HAL_GPIO_WritePin()
HAL_GPIO_TogglePin()
HAL_Delay()
```

### AN2586 и UM1075

К первой работе относятся понятия:

```text
Boot
Reset
ST-LINK V2
SWD
SWDIO
SWCLK
GND
3.3V
```

## Как используются первоисточники

Методика курса:

```text
тема лабораторной
↓
необходимая теория объясняется в самой ЛР
↓
указывается документ-первоисточник
↓
оригинал используется только для углубления или проверки технической детали
```

То есть первоисточник подтверждает техническую основу материала, но **не является обязательным внешним шагом** для начинающего студента.

## Разница между типами документов

```text
Datasheet
→ характеристики конкретного MCU и выводы
```

```text
Reference Manual
→ работа внутренних периферийных блоков
```

```text
Programming Manual
→ архитектура процессорного ядра
```

```text
HAL/LL Manual
→ программные функции библиотек ST
```

```text
Application Note
→ инженерные рекомендации по отдельной теме
```
