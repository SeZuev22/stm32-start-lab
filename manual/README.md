[← На главную страницу](../README.md) | [Перейти к учебному курсу →](../course/README.md)

## О пособии

**STM32 Start Lab** — учебное пособие для студентов, которые впервые начинают работать с микроконтроллерами STM32.

Текущий учебный трек построен вокруг проверенной конфигурации:

**Windows → Blue Pill → STM32F103C8T6 → ST-LINK V2 → STM32CubeMX → STM32CubeIDE → HAL**

Главная цель пособия — провести студента через полный цикл разработки проекта на STM32:

```text
оборудование
↓
программное обеспечение
↓
документация
↓
конфигурация микроконтроллера
↓
программирование
↓
сборка проекта
↓
прошивка
↓
проверка на реальном оборудовании
```

Пособие ориентировано не на механическое копирование готового кода, а на понимание того:

- что делает студент;
- зачем он это делает;
- где находится нужная настройка;
- почему выбирается именно такое решение;
- как проверить правильность результата;
- что делать при возникновении ошибки.

- включения интерфейса SWD;

В пособии рассматривается установка STM32CubeMX и его настройка для работы с локальными MCU Packages.

STM32CubeF1 — программный пакет для семейства STM32F1.

В учебном треке используется:

```text
STM32CubeF1 v1.8.0
```

Пакет содержит:

- HAL-драйверы;
- CMSIS;
- системные файлы;
- шаблоны;
- программные компоненты для STM32F1.

Пакет устанавливается локально через STM32CubeMX.

STM32CubeIDE используется для:

- редактирования программы;

# Раздел 8. USER CODE sections

STM32CubeMX автоматически генерирует значительную часть программы.

Для пользовательского кода используются специальные области:

```c
/* USER CODE BEGIN ... */

/* USER CODE END ... */
```

Пользовательский код рекомендуется размещать именно внутри этих областей.

Это необходимо для того, чтобы при повторной генерации проекта STM32CubeMX не удалил написанный студентом код.

---

# Раздел 9. Библиотека HAL

HAL расшифровывается как:

```text
Hardware Abstraction Layer
```

HAL предоставляет готовые функции для работы с периферией STM32.

В первой лабораторной используются:

```c
HAL_GPIO_WritePin()
HAL_Delay()
```

---

## HAL_GPIO_WritePin()

Используется для задания логического состояния цифрового выхода.

Пример:

```c
HAL_GPIO_WritePin(LED_GPIO_Port, LED_Pin, GPIO_PIN_RESET);
```

---

## HAL_Delay()

Используется для создания задержки.

Пример:

```c
HAL_Delay(300);
```

означает задержку:

```text
300 мс
```

---

## HAL_GPIO_TogglePin()

Функция:

```c
HAL_GPIO_TogglePin(LED_GPIO_Port, LED_Pin);
```

инвертирует текущее состояние GPIO:

```text
0 → 1
1 → 0
```

В ЛР №1 эта функция используется в обязательной самостоятельной части. Студент должен понимать, что один вызов TogglePin означает одно изменение состояния, а для полного мигания от OFF обратно к OFF требуется два переключения.

---

# Раздел 10. Основной код Blink

Пример базового алгоритма:

```c
for (int i = 0; i < 5; i++)
{
    HAL_GPIO_WritePin(LED_GPIO_Port, LED_Pin, GPIO_PIN_RESET);
    HAL_Delay(300);

    HAL_GPIO_WritePin(LED_GPIO_Port, LED_Pin, GPIO_PIN_SET);
    HAL_Delay(300);
}

HAL_Delay(2000);
```

Код выполняется внутри:

```c
while (1)
```

поэтому последовательность повторяется бесконечно.

# Раздел 14. Типичные ошибки

В пособии рассматриваются реальные проблемы, возникавшие при подготовке учебного стенда.

---

## STM32CubeMX требует Java Runtime Environment

Рассматривается случай, когда CubeMX не запускается при пользовательской установке.

---

## NSIS Error при установке STM32CubeIDE

Рассматривается запуск установщика из короткого пути без кириллицы.

---

## STM32CubeMX пытается скачать MCU Package

Причина:

выбрана более новая версия firmware package, которой нет локально.

Решение:

отключить:

```text
Use latest available version
```

и выбрать:

```text
STM32CubeF1 v1.8.0
```

---

## ST-LINK не определяется

Проверяются:

- драйвер;
- USB;
- GND;
- SWDIO;
- SWCLK;
- питание;
- настройка Serial Wire.

---

## Проект собирается, но LED не мигает

Проверяются:

- PC13;
- GPIO Output;
- active-low;
- положение BOOT0;
- наличие успешной прошивки;
- правильность кода.

# Раздел 17. Обязательная самостоятельная часть

После базового Blink студент **обязан** выполнить самостоятельную часть.

Она состоит из двух этапов:

```text
исследование HAL_GPIO_TogglePin()
↓
индивидуальный вариант из 10 заданий
```

В индивидуальном варианте требуется реализовать две серии миганий с разным количеством импульсов и временными параметрами, используя:

```c
HAL_GPIO_TogglePin()
HAL_Delay()
for
while (1)
```

Для полного цикла рассчитывается:

```text
TA = NA × (tA_ON + tA_OFF)
TB = NB × (tB_ON + tB_OFF)
Tcycle = TA + PAB + TB + PCYCLE
```

Готовое решение индивидуального варианта в пособии не приводится. Все необходимые для его выполнения средства объясняются в ЛР №1.
