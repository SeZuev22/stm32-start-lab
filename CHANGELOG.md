# Changelog

Все заметные изменения проекта STM32 Start Lab фиксируются в этом файле.

## [Unreleased]

### Добавлено
- базовая структура проекта;
- инструкции для Windows и Linux;
- разделы для Blue Pill STM32F103C8T6 и Black Pill STM32F411CEU6;
- описание программного обеспечения;
- паспорт версий offline-комплекта;
- SHA-256 контрольные суммы файлов.

### В работе
- проверка полной offline-установки;
- установка STM32CubeF1 и STM32CubeF4 из локальных архивов;
- пример Blink для Blue Pill;
- пример Blink для Black Pill;
- пошаговое учебное пособие;
- подготовка первого стабильного релиза v1.0.
