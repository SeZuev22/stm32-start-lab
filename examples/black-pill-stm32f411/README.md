# Примеры для Black Pill — STM32F411CEU6

В этом разделе будут размещаться учебные проекты для платы Black Pill на микроконтроллере STM32F411CEU6.

## Планируемые примеры

### 01 — Blink

Первый учебный проект.

Цель:

- настроить GPIO в STM32CubeMX;
- сгенерировать проект;
- открыть проект в STM32CubeIDE;
- написать программу на HAL;
- собрать проект;
- прошить микроконтроллер через ST-LINK V2;
- проверить работу встроенного светодиода.

Проект будет добавлен после полной проверки процесса создания, сборки и прошивки.

## Структура

В дальнейшем примеры будут размещаться примерно так:

- `01_blink/`
- последующие учебные проекты будут добавляться по мере развития пособия.
