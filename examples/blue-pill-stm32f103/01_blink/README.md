# 01 — Blink на Blue Pill

Первый учебный проект STM32 Start Lab.

В этом примере используется плата **Blue Pill** на микроконтроллере **STM32F103C8T6**.

Цель проекта — пройти полный базовый путь:

**настройка STM32CubeMX → генерация проекта → написание программы → сборка → прошивка через ST-LINK V2 → проверка работы на реальной плате.**

---

## 1. Используемое оборудование

- Blue Pill — STM32F103C8T6;
- программатор ST-LINK V2;
- соединительные провода;
- компьютер с Windows;
- STM32CubeMX;
- STM32CubeIDE.

---

## 2. Что делает программа

Встроенный светодиод платы:

1. включается на 300 мс;
2. выключается на 300 мс;
3. выполняет 5 таких миганий;
4. после этого программа ждёт 2 секунды;
5. последовательность повторяется бесконечно.

---

## 3. Выбор микроконтроллера

В STM32CubeMX используется:

`STM32F103C8T6`

Для проекта используется установленный локально пакет:

`STM32CubeF1 v1.8.0`

При работе offline необходимо отключить:

`Use latest available version`

и выбрать локальную версию пакета вручную.

---

## 4. Настройка интерфейса отладки

В STM32CubeMX:

`System Core → SYS → Debug → Serial Wire`

Интерфейс **Serial Wire Debug (SWD)** используется для программирования и отладки микроконтроллера через ST-LINK.

После включения SWD задействуются выводы:

- PA13 — SWDIO;
- PA14 — SWCLK.

---

## 5. Настройка встроенного светодиода

На используемой плате Blue Pill встроенный пользовательский светодиод подключён к выводу:

`PC13`

В STM32CubeMX вывод PC13 настраивается как:

`GPIO_Output`

и получает пользовательскую метку:

`LED`

Начальный уровень:

`High`

В используемой конфигурации светодиод является **active-low**:

- логический 0 — светодиод включён;
- логическая 1 — светодиод выключен.

## 7. Основной код программы

Пользовательский код размещается внутри специальных областей:

```c
/* USER CODE BEGIN 3 */
// Цикл for повторяет код внутри фигурных скобок 5 раз.
// Переменная i используется как счётчик повторений.
// Начальное значение i = 0.
// Условие i < 5 означает: выполнять цикл, пока i меньше 5.
// i++ увеличивает i на единицу после каждого прохода цикла.
for (int i = 0; i < 5; i++)
{
    // HAL_GPIO_WritePin() устанавливает логический уровень на выбранном GPIO.

    // LED_GPIO_Port — порт светодиода.
    // В данном проекте это GPIOC.

    // LED_Pin — вывод, которому в STM32CubeMX была присвоена метка LED.
    // В данном проекте это PC13.

    // GPIO_PIN_RESET устанавливает логический 0.
    // Светодиод Blue Pill active-low,
    // поэтому логический 0 включает светодиод.
    HAL_GPIO_WritePin(LED_GPIO_Port, LED_Pin, GPIO_PIN_RESET);

    // HAL_Delay() создаёт программную задержку в миллисекундах.
    // Здесь светодиод остаётся включённым 300 мс.
    HAL_Delay(300);

    // GPIO_PIN_SET устанавливает логическую 1.
    // При active-low подключении это выключает светодиод.
    HAL_GPIO_WritePin(LED_GPIO_Port, LED_Pin, GPIO_PIN_SET);

    // Светодиод остаётся выключенным 300 мс.
    HAL_Delay(300);
}

// После пяти миганий выполняется дополнительная пауза 2 секунды.
HAL_Delay(2000);

// После этого внешний цикл while(1)
// снова запускает всю последовательность.
/* USER CODE END 3 */

8. Что такое HAL
В проекте используется библиотека HAL — Hardware Abstraction Layer.
Она позволяет работать с периферией STM32 через готовые функции.
Например:
HAL_GPIO_WritePin()
используется для изменения состояния цифрового выхода GPIO.
HAL_Delay()
создаёт задержку в миллисекундах.
