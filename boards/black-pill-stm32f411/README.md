# Black Pill — STM32F411CEU6

Этот раздел посвящён работе с платой Black Pill на микроконтроллере STM32F411CEU6.

## Что будет рассмотрено

- подключение платы через ST-LINK V2;
- выбор микроконтроллера STM32F411CEU6 в STM32CubeMX;
- установка локального пакета STM32CubeF4;
- настройка GPIO;
- настройка тактирования;
- генерация проекта для STM32CubeIDE;
- написание первой программы на HAL;
- сборка проекта;
- прошивка микроконтроллера;
- проверка работы встроенного светодиода.

## Используемые инструменты

- STM32CubeMX;
- STM32CubeIDE;
- STM32CubeF4;
- ST-LINK V2;
- библиотека HAL.

## Итог первого практического примера

После выполнения инструкции плата должна запускать простую программу мигания встроенным светодиодом.

Подробная пошаговая инструкция будет добавлена после проверки полного процесса установки и прошивки.
