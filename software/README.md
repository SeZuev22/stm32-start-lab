# Программное обеспечение

В этом разделе собрана информация о программном обеспечении, необходимом для работы с платами STM32 Blue Pill и Black Pill.

## Основные программы

### STM32CubeMX

Используется для:

- выбора микроконтроллера;
- настройки выводов GPIO;
- настройки тактирования;
- настройки периферии;
- генерации проекта.

Целевая версия для первого релиза комплекта:

- STM32CubeMX 6.18.1

### STM32CubeIDE

Используется для:

- написания программы на языке C;
- работы с библиотекой HAL;
- компиляции проекта;
- прошивки микроконтроллера;
- отладки программы.

Целевая версия для первого релиза комплекта:

- STM32CubeIDE 2.2.0

### ST-LINK

Для подключения и прошивки плат используется программатор:

- ST-LINK V2

Для Windows будет отдельно сохранён драйвер ST-LINK.

## MCU Packages

Для Blue Pill требуется:

- STM32CubeF1

Для Black Pill требуется:

- STM32CubeF4

MCU Packages будут устанавливаться локально, без необходимости загрузки через STM32CubeMX из интернета.

## Offline-режим

Главная задача комплекта — обеспечить возможность:

1. скачать все необходимые файлы заранее;
2. отключить интернет;
3. установить программное обеспечение;
4. установить локальные MCU Packages;
5. создать проект;
6. собрать проект;
7. прошить STM32 через ST-LINK V2.

Большие установочные файлы будут размещаться в разделе Releases проекта.
