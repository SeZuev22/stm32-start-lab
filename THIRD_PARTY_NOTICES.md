# Third-party software

Проект STM32 Start Lab использует программное обеспечение и библиотеки сторонних разработчиков.

## STMicroelectronics

В учебном комплекте используются или планируются к использованию:

- STM32CubeMX;
- STM32CubeIDE;
- STM32CubeProgrammer;
- ST-LINK Driver;
- STM32CubeF1;
- STM32CubeF4.

Указанные программные продукты принадлежат STMicroelectronics и распространяются на условиях соответствующих лицензионных соглашений.

Проект STM32 Start Lab не является официальным продуктом STMicroelectronics.

## Распространение установочных файлов

Перед публикацией стороннего программного обеспечения в GitHub Releases необходимо отдельно проверить условия распространения каждого программного пакета.

До завершения этой проверки установочные файлы не публикуются в стабильном релизе проекта.

## Собственные материалы проекта

К собственным материалам STM32 Start Lab относятся:

- учебные инструкции;
- пояснения;
- схемы и изображения, созданные авторами проекта;
- примеры программ;
- структура учебного пособия;
- вспомогательные файлы проекта.

Условия лицензирования собственных материалов будут указаны отдельно.
