# STM32 Start Lab

Практико-ориентированный учебный курс по микроконтроллерам STM32 для бакалавриата и магистратуры технических направлений.

Текущий проверенный трек:

**Windows → Blue Pill STM32F103C8T6 → ST-LINK V2 → STM32CubeMX → STM32CubeIDE → HAL**

Курс строится по принципу:

```text
инженерная задача
↓
настройка микроконтроллера
↓
рабочий пример
↓
физический результат
↓
самостоятельная модификация
↓
объяснение и защита решения
```

## С чего начать

Материалы следует проходить последовательно:

```text
00 — Подготовка рабочего места
↓
ЛР №1 — Дискретный выход STM32 и диагностическая световая сигнализация
```

1. **[Подготовить рабочее место](course/00-getting-started/README.md)**
2. **[Выполнить лабораторную работу №1](course/01-blink/README.md)**

В первой лабораторной встроенный LED используется как модель дискретной диагностической индикации. Цель работы — не само мигание светодиода, а понимание цепочки:

```text
состояние программы
↓
HAL
↓
GPIO
↓
физический выход
↓
диагностический сигнал
```

## Оборудование

Минимальный комплект для ЛР №1:

- Blue Pill с **STM32F103C8T6**;
- ST-LINK V2 или совместимый SWD-программатор;
- соединительные провода Dupont;
- USB-подключение программатора к ПК.

**[Требования к оборудованию и примеры закупки](resources/hardware/README.md)**

Для каждой последующей лабораторной работы перечень дополнительного оборудования должен приводиться отдельно.

## Учебная модель курса

Каждая лабораторная работа должна включать:

1. практическую постановку задачи;
2. связь с реальными инженерными применениями;
3. необходимый минимум теории;
4. проверенный базовый пример;
5. пояснение используемых настроек и функций;
6. самостоятельное задание;
7. проверку на реальном оборудовании;
8. критерии приёмки;
9. контрольные вопросы;
10. требования к отчёту и защите.

Готовый индивидуальный ответ студенту не предоставляется: в курсе показывается принцип, после чего студент применяет его самостоятельно.

**[Карта курса](course/README.md)**

## Бакалавриат и магистратура

Практическая часть может быть общей, а глубина защиты различается.

Для базового уровня требуется уверенно настроить периферию, применить HAL и объяснить алгоритм. Для углублённого уровня дополнительно рассматриваются автоматически сгенерированный код, исходники HAL, связь HAL с регистрами и ограничения выбранного программного решения.
