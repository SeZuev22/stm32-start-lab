Учебный практикум по микроконтроллерам STM32 для начинающих.

Текущий проверенный учебный трек:

**Windows → Blue Pill STM32F103C8T6 → ST-LINK V2 → STM32CubeMX → STM32CubeIDE → HAL**

## 2. Выполните лабораторную работу №1

### GPIO Output — Blink

В первой работе вы самостоятельно пройдёте полный цикл разработки:

```text
STM32CubeMX
↓
конфигурация STM32F103C8T6
↓
GPIO
↓
HAL
↓
STM32CubeIDE
↓
Build
↓
ST-LINK V2
↓
Flash
↓
результат на реальной плате
```

Ожидаемый результат:

**5 миганий светодиода → пауза 2 секунды → повтор.**

➡️ **[Лабораторная работа №1 — Blink](course/01-blink/README.md)**

# 🎓 Учебный курс

Полная карта курса:

➡️ **[STM32 Start Lab — учебный курс](course/README.md)**

Каждая лабораторная работа строится по единому принципу:

1. цель;
2. необходимая теория;
3. оборудование;
4. документация;
5. схема подключения;
6. настройка STM32CubeMX;
7. объяснение настроек;
8. программа;
9. объяснение программы;
10. сборка;
11. прошивка;
12. проверка;
13. типичные ошибки;
14. контрольные вопросы;
15. самостоятельное задание;
16. требования к отчёту;
17. вывод.

Главная цель — **не просто скопировать готовый код, а понять весь процесс разработки STM32**.
