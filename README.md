# STM32 Start Lab

Учебный комплект для первого знакомства с микроконтроллерами STM32.

Проект предназначен для студентов, которые раньше не работали со STM32 и хотят пройти путь **от установки программного обеспечения до запуска первой программы на реальной плате**.

---

# 🚀 Начните здесь

## 📦 Шаг 0. Скачать всё необходимое

Перед началом работы скачайте файлы из подготовленного комплекта:

➡️ **[Скачать STM32 Start Lab для Windows](ССЫЛКА_НА_RELEASE)**

Для первого занятия нужны:

| Файл | Для чего нужен | Обязательно |
|---|---|---|
| `SetupSTM32CubeMX-6.18.1-Win-x86_64.zip` | Настройка микроконтроллера и генерация проекта | Да |
| `stm32cubeide_2.2.0-Win-x86_64.exe.zip` | Написание, сборка и прошивка программы | Да |
| `stm32cubef1.zip` | Локальный пакет для STM32F103C8T6 | Да |
| `stsw-link009.zip` | Драйвер ST-LINK V2 | Резервный вариант |
| `SetupSTM32CubeProgrammer_win64.zip` | Диагностика и отдельная работа с ST-LINK | Необязательно |
| `VERSIONS.txt` | Проверенные версии комплекта | Рекомендуется |
| `SHA256SUMS.txt` | Проверка целостности файлов | Необязательно для новичка |

> Для первого проекта **Blue Pill Blink** никаких других программ скачивать не требуется.

Если вы впервые открыли этот репозиторий, **не нужно изучать все папки подряд**.

Для первого запуска используйте этот маршрут:

### Шаг 1. Подготовьте оборудование

Для первого занятия потребуется:

- Blue Pill — STM32F103C8T6;
- ST-LINK V2;
- 4 соединительных провода;
- компьютер с Windows.

### Шаг 2. Установите программное обеспечение

Откройте пошаговую инструкцию:

➡️ [Полная инструкция для Windows](course/00-getting-started/README.md)

Она проводит через:

**установку STM32CubeMX → установку STM32CubeF1 → установку STM32CubeIDE → настройку offline-режима → создание проекта → прошивку платы.**

### Шаг 3. Выполните первый проект

После установки программ переходите к первому примеру:

➡️ [Проект 01 — Blink на Blue Pill](examples/blue-pill-stm32f103/01_blink/README.md)

Результат:

**светодиод мигает 5 раз → пауза 2 секунды → цикл повторяется.**

# 🎓 Рекомендуемый порядок обучения

После успешного Blink:

```text
01 — Blink
↓
02 — GPIO Input / Button
↓
03 — UART
↓
04 — External Interrupt
↓
05 — Timer
↓
06 — PWM
↓
07 — ADC
↓
08 — I2C / SPI
```

Главная задача первого проекта — не просто заставить LED мигать, а понять базовую цепочку разработки STM32:

**конфигурация → код → сборка → прошивка → физический результат.**
