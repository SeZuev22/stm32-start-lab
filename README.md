# STM32 Start Lab

Учебный проект для первого знакомства с микроконтроллерами STM32.

Цель проекта — провести студента по полному пути:

**подготовка ПО → offline-установка → настройка среды → создание проекта → программирование → сборка → прошивка → проверка работы на реальной плате.**

Проект ориентирован на начинающих пользователей, которые раньше не работали со STM32.

## Проверка файлов

Для установочных файлов формируются контрольные суммы SHA-256.

Они позволяют проверить, что скачанный файл:

- не повреждён;
- полностью загрузился;
- совпадает с протестированной версией.

Файл контрольных сумм:

## Первый практический результат

После прохождения первой части студент должен уметь:

1. установить необходимое программное обеспечение;
2. установить MCU Package без загрузки из интернета;
3. создать новый проект STM32;
4. настроить GPIO;
5. сгенерировать проект;
6. открыть его в STM32CubeIDE;
7. написать простую программу на HAL;
8. собрать проект;
9. прошить микроконтроллер через ST-LINK V2;
10. проверить работу встроенного светодиода.

---

## Маршрут обучения

Если вы впервые работаете со STM32, рекомендуется идти в таком порядке:

1. Выберите свою операционную систему:
   - Windows;
   - Linux.

2. Подготовьте программное обеспечение.

3. Выберите плату:
   - Blue Pill;
   - Black Pill.

4. Установите соответствующий MCU Package.

5. Подключите плату через ST-LINK V2.

6. Создайте первый проект Blink.

7. Соберите и прошейте проект.

8. Разберите структуру программы и работу HAL.

## Offline-режим

Одна из задач проекта — обеспечить возможность прохождения базового курса без постоянного доступа к серверам STMicroelectronics.

После предварительного получения комплекта студент должен иметь возможность:

- установить основные программы;
- установить локальные MCU Packages;
- создать проект;
- собрать программу;
- прошить микроконтроллер.
