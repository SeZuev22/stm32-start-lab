# STM32 Start Lab

Учебный практикум по микроконтроллерам STM32 для начинающих.

Текущий проверенный трек:

**Windows → Blue Pill STM32F103C8T6 → ST-LINK V2 → STM32CubeMX → STM32CubeIDE → HAL**

Не изучайте папки репозитория вручную. Выполняйте курс по порядку:

```text

↓
01 — Лабораторная работа №1: GPIO Output / Blink
```

# Что требуется приобрести

Минимальный комплект:

```text
Blue Pill STM32F103C8T6
ST-LINK V2 / совместимый SWD-программатор
4 провода Dupont
USB-подключение программатора к ПК
```

# Учебный курс

➡️ **[Карта курса](course/README.md)**

Каждая лабораторная работа содержит:

1. обязательную базовую часть;
2. объяснение настроек и кода;
3. проверку на реальном оборудовании;
4. обязательный новый элемент для самостоятельного разбора;
5. 10 индивидуальных вариантов;
6. контрольные вопросы;
7. требования к отчёту;
8. критерии защиты.

Главная задача — не скопировать готовый код, а понять решение и самостоятельно применить изученный принцип.
