# STM32 Start Lab

Практико-ориентированный учебный курс по STM32 для начинающих.

Текущий проверенный трек:

**Windows → Blue Pill STM32F103C8T6 → ST-LINK V2 → STM32CubeMX → STM32CubeIDE → HAL**

Главный принцип курса:

```text
понять задачу
↓
собрать рабочий пример
↓
увидеть физический результат
↓
связать его с инженерной практикой
↓
изменить решение самостоятельно
↓
объяснить результат
```

# 👋 Впервые здесь?

Выполняйте курс последовательно:

```text
00 — Подготовка рабочего места
↓
01 — Дискретный выход STM32 и диагностическая световая сигнализация
```

➡️ **[Шаг 00 — подготовка рабочего места](course/00-getting-started/README.md)**

➡️ **[Лабораторная работа №1](course/01-blink/README.md)**

В ЛР №1 светодиод используется не как самоцель, а как простейшая модель дискретной индикации состояния устройства:

```text
GPIO
↓
HAL_GPIO_WritePin()
↓
HAL_GPIO_TogglePin()
↓
диагностический сигнал READY
↓
самостоятельный инженерный сценарий
```

# Учебный курс

➡️ **[Карта курса](course/README.md)**

Каждая лабораторная работа должна содержать:

1. практическую задачу;
2. объяснение, где принцип применяется;
3. базовый пример;
4. проверку на реальном оборудовании;
5. самостоятельное задание;
6. критерии приёмки;
7. вопросы для защиты.
