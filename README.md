# STM32 Start Lab

Учебный комплект для первого знакомства с микроконтроллерами STM32.

Поддерживаемые платы:

- Blue Pill — STM32F103C8T6
- Black Pill — STM32F411CEU6

Поддерживаемые операционные системы:

- Windows
- Linux

## Что будет в комплекте

- STM32CubeMX
- STM32CubeIDE
- STM32Cube MCU Packages
- поддержка ST-LINK V2
- пошаговое учебное пособие
- примеры проектов на HAL
- offline-установка без обращения к онлайн-репозиториям ST

## Текущий статус

Проект находится в разработке.

План первой версии:

1. Подготовить установщики и MCU-пакеты.
2. Проверить offline-установку.
3. Создать проект Blink для Blue Pill.
4. Создать проект Blink для Black Pill.
5. Подготовить инструкцию для Windows.
6. Подготовить инструкцию для Linux.
7. Выпустить первый стабильный Release `v1.0`.
