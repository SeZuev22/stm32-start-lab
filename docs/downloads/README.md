# 📦 Что скачать для первого запуска

[← На главную](../../README.md)

Этот раздел содержит программное обеспечение, необходимое для первого проекта **STM32 Start Lab**.

Если вы впервые работаете со STM32, не нужно устанавливать всё подряд.

Для первого проекта **Blue Pill Blink** нужны только три основных компонента.

---

# Минимальный комплект

## 1. STM32CubeMX 6.18.1

**Для чего нужен:** настройка микроконтроллера и генерация проекта.

Файл:

```text
SetupSTM32CubeMX-6.18.1-Win-x86_64.zip
```

STM32CubeMX позволяет:

- выбрать STM32F103C8T6;
- настроить выводы;
- включить SWD;
- настроить GPIO;
- создать проект для STM32CubeIDE.

---

## 2. STM32CubeIDE 2.2.0

**Для чего нужен:** написание программы, сборка и прошивка микроконтроллера.

Файл:

```text
stm32cubeide_2.2.0-Win-x86_64.exe.zip
```

STM32CubeIDE используется для:

- редактирования исходного кода;
- компиляции;
- сборки проекта;
- работы со ST-LINK;
- записи программы во Flash;
- отладки.

---

## 3. STM32CubeF1 v1.8.0

**Для чего нужен:** локальный firmware package для семейства STM32F1.

Файл:

```text
stm32cubef1.zip
```

Этот пакет необходим для работы с:

```text
STM32F103C8T6
```

Он устанавливается непосредственно из STM32CubeMX:

```text
INSTALL / REMOVE
→ From Local...
```

Архив предварительно распаковывать не нужно.

---

# Итого для первого занятия

Для выполнения проекта Blink нужны:

```text
1. STM32CubeMX 6.18.1
2. STM32CubeIDE 2.2.0
3. STM32CubeF1 v1.8.0
```

После скачивания переходите к пошаговой установке:

➡️ **[Установка и настройка под Windows](../windows/README.md)**

# Дополнительные файлы

Следующие программы не обязательны для первого Blink.

## ST-LINK Driver

Файл:

```text
stsw-link009.zip
```

В проверенной конфигурации драйвер ST-LINK устанавливается вместе с STM32CubeIDE.

Используйте отдельный пакет только в том случае, если ST-LINK не определяется компьютером.

---

## STM32CubeProgrammer

Файл:

```text
SetupSTM32CubeProgrammer_win64.zip
```

Для первого проекта устанавливать STM32CubeProgrammer не требуется.

Он может понадобиться позже для:

- диагностики подключения;
- ручной прошивки;
- просмотра памяти;
- работы с Option Bytes.

---

# Служебные файлы комплекта

## VERSIONS.txt

Содержит список версий программ, с которыми проверялось учебное пособие.

## SHA256SUMS.txt

Содержит контрольные суммы SHA-256.

Они позволяют проверить, что скачанный файл не повреждён и соответствует подготовленному комплекту.

Для первого занятия проверка SHA-256 не обязательна.
