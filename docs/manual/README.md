# Учебное пособие STM32 Start Lab

Это пособие предназначено для студентов, которые впервые начинают работать с микроконтроллерами STM32.

Главная цель — пройти полный путь от подготовки программного обеспечения до запуска первой программы на реальной плате.

## Структура пособия

### 1. Введение
- что такое микроконтроллер;
- что такое STM32;
- чем Blue Pill отличается от Black Pill;
- зачем нужен программатор ST-LINK;
- что такое HAL.

### 2. Подготовка оборудования
- Blue Pill — STM32F103C8T6;
- Black Pill — STM32F411CEU6;
- ST-LINK V2;
- USB-кабель;
- схема подключения программатора к плате.

### 3. Подготовка offline-комплекта
- состав программного обеспечения;
- STM32CubeMX;
- STM32CubeIDE;
- STM32CubeProgrammer;
- ST-LINK Driver;
- STM32CubeF1;
- STM32CubeF4;
- проверка SHA-256.

### 4. Установка под Windows
- установка STM32CubeMX;
- установка STM32CubeIDE;
- установка ST-LINK Driver;
- установка STM32CubeProgrammer;
- настройка локального MCU Package;
- проверка работы без интернета.

### 5. Установка под Linux
- установка STM32CubeMX;
- установка STM32CubeIDE;
- настройка ST-LINK;
- установка MCU Packages;
- особенности прав доступа и USB.

### 6. Первый проект для Blue Pill
- создание проекта в STM32CubeMX;
- выбор STM32F103C8T6;
- настройка GPIO;
- настройка тактирования;
- генерация проекта;
- открытие проекта в STM32CubeIDE;
- структура проекта;
- USER CODE sections;
- написание программы Blink на HAL;
- сборка проекта;
- прошивка;
- проверка работы светодиода.

### 7. Первый проект для Black Pill
- создание проекта в STM32CubeMX;
- выбор STM32F411CEU6;
- настройка GPIO;
- настройка тактирования;
- генерация проекта;
- написание программы Blink на HAL;
- сборка;
- прошивка;
- проверка работы.

### 8. Как работает программа
- функция main();
- бесконечный цикл while(1);
- GPIO;
- HAL_GPIO_WritePin();
- HAL_GPIO_TogglePin();
- HAL_Delay();
- активный высокий и активный низкий уровень;
- роль тактирования микроконтроллера.

### 9. Типичные ошибки
- CubeIDE не видит ST-LINK;
- плата не прошивается;
- неверно выбран микроконтроллер;
- отсутствует MCU Package;
- ошибка сборки;
- светодиод не мигает;
- неверное подключение SWD.

### 10. Итог
После выполнения пособия студент должен уметь:

- установить необходимое программное обеспечение;
- работать без постоянного подключения к интернету;
- создать проект STM32;
- настроить GPIO;
- написать простую программу на HAL;
- собрать проект;
- прошить микроконтроллер;
- проверить работу программы на реальной плате.
