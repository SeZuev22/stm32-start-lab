# Установка и настройка под Windows

В этом разделе приведена пошаговая инструкция по подготовке рабочего места для программирования плат STM32.

Поддерживаемые платы:

- Blue Pill — STM32F103C8T6
- Black Pill — STM32F411CEU6

## Что потребуется

- STM32CubeMX
- STM32CubeIDE
- драйвер ST-LINK
- программатор ST-LINK V2
- USB-кабель
- одна из поддерживаемых плат STM32

## Порядок работы

1. Установить STM32CubeMX.
2. Установить STM32CubeIDE.
3. Установить драйвер ST-LINK.
4. Установить локальный MCU Package для своей платы.
5. Подключить плату через ST-LINK V2.
6. Создать первый проект.
7. Собрать и прошить программу Blink.

Подробная инструкция будет добавляться по мере проверки полного процесса установки.
