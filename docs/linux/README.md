# Установка и настройка под Linux

В этом разделе будет приведена пошаговая инструкция по подготовке рабочего места для программирования плат STM32 под Linux.

Поддерживаемые платы:

- Blue Pill — STM32F103C8T6
- Black Pill — STM32F411CEU6

## Что потребуется

- STM32CubeMX
- STM32CubeIDE
- средства работы с ST-LINK
- программатор ST-LINK V2
- одна из поддерживаемых плат STM32

## Порядок работы

1. Установить STM32CubeMX.
2. Установить STM32CubeIDE.
3. Настроить работу ST-LINK.
4. Установить локальный MCU Package для своей платы.
5. Подключить плату.
6. Создать первый проект.
7. Собрать и прошить программу Blink.

Инструкция будет отдельно проверена на Linux-системе.
